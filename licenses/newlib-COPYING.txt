Newlib C Library — Applicable Notices for Linked Runtime Routines

Firmware images built with the Arm GNU Toolchain (arm-none-eabi-gcc) link minimal
C runtime / string routines from Newlib alongside Raspberry Pi Pico SDK's BSD-3-Clause
pico_clib_interface / bootrom wrappers and GCC's libgcc (GPLv3 with GCC Runtime
Library Exception v3.1).
